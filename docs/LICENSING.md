# Licensing gate

The intended application license is `AGPL-3.0-only`, consistent with the research repository's declared license.

This foundation contains a short SPDX identifier file rather than a full AGPL license text.
Before publishing/distributing, include the full official AGPLv3 text as `LICENSE`,
review notices for any code transferred from the research repository,
and verify the license of the external `isothermal-pipe-sim` dependency.
Do not treat the research license as evidence of the forward solver's license.
